Ramure

Client git de bureau (Tauri · Rust · Vue) centré sur le commit graph : recherche instantanée, gestes par drag & drop et menu contextuel, rebase interactif visuel, annulation de toute opération.

Thème des maquettes
Dépôt d'exemple : sherpaLigne : 28 px (compact 22 px)Lanes : 16 pxSpec : spec-ramure.md

Le graph est l'écran

On ouvre un dépôt, on voit le graph. Aucun tableau de bord intermédiaire.

Dire ce qui va se passer

Chaque geste annonce la commande exacte avant de l'exécuter.

Tout est réversible

⌘Z annule reset, rebase, merge, suppression. On confirme seulement l'irréversible.

Clavier d'abord

Chaque entrée de menu existe aussi dans la palette ⌘K.

D

Drag & drop

On attrape une pastille de ref, les cibles valides s'éclairent et l'action par défaut s'écrit sous le curseur. Au dépôt, un menu court classe les actions de la plus probable à la plus rare, avec la commande git équivalente.

  • Branche → branche : rebase, merge dans un sens ou l'autre, fast-forward si possible.
  • Branche → commit : rebase sur ce commit, reset à ce commit.
  • Branche → sa distante : push (force-with-lease si divergente).
  • Commit(s) → branche : cherry-pick.
  • Si un checkout est nécessaire, le libellé le dit : « Checkout main puis merge… ».
  • esc annule le glisser à tout moment.
